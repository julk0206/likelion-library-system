# Guide for Documentation

`doc` 폴더는 다음과 같은 목적으로 생성 하였습니다.

## 1. 문서화

프로젝트를 진행하며 학습하게 된 내용, 또는 정리가 필요한 이슈를 작성해 주세요. 특별히 범주에 제한은 없으나, 프로젝트를 진행하며 학습 또는 서치, 연구 한 내용이면

팀원들에게 보다 도움이 됩니다.

## 2. 저장

히스토리를 남기기 위함입니다. `doc` 을 이용해 저장 공유 하셨을 때 이점이 있는 예시로는 다음과 같습니다.

1. 이슈로 공유하기엔 내용이 너무 방대 할 때

2. 참고 및 블로깅 용 백업

## 3. 공유

지식 공유자로서 정보를 공유 하기 위해, 내용을 어떻게 정리해여 잘 전달이 될 수 있을 지 연습 할 수 있습니다.
